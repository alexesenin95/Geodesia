# Сайт МБУ «ВЯЗ»

Сайт Центра стратегического планирования Волгограда «ВЯЗ» — лендинг,
внутренние страницы и панель управления контентом.

Дизайн создан в Claude Design по референсу [lda-design.co.uk](https://www.lda-design.co.uk)
и экспортирован в этот репозиторий.

## Структура

| Файл | Назначение |
|------|------------|
| `index.html` | Весь сайт (это исходный файл Claude Design `Сайт ВЯЗ.dc.html`). Содержит разметку `x-dc`, стили и логику CMS. |
| `support.js` | Рантайм Claude Design: подгружает React/ReactDOM/Babel с unpkg и рендерит `index.html`. |
| `image-slot.js` | Компонент `<image-slot>` — слоты для загрузки изображений (иконки манифеста, фото команды). |
| `assets/` | Логотипы. |
| `.image-slots.state.json` | Сохранённые в слоты изображения. |

## Страницы

Главная (карусель проектов + новости), Проекты (с фильтрами), О нас
(о бюро, **манифест — 6 принципов со слотами под векторные иконки**, команда),
Услуги, КРТ (комплексное развитие территорий + карточки площадок),
Контакты, Вакансии, страницы проекта и площадки.

## Панель управления

Открывается из футера → «Панель управления».

- **Демо-доступ:** `admin` / `vyaz`
- Управление: проекты, новости, услуги, КРТ, команда, манифест, настройки.
- ⚠️ Сейчас данные сохраняются только в браузере (`localStorage`) — это
  прототип админки. Для реального многопользовательского управления нужен
  бэкенд (см. «Дальнейшие шаги»).

## Запуск локально

Открывать файл напрямую нельзя (нужен http). Поднимите статический сервер:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

Нужен доступ в интернет — React/Babel грузятся с `unpkg.com`.

## Деплой

Это статический сайт — подойдёт любой статический хостинг (РФ-хостинг,
Nginx, объектное хранилище и т.п.). Достаточно выложить все файлы как есть.

## Дальнейшие шаги

1. **Реальные изображения** проектов/площадок (сейчас — градиентные
   заглушки) и **векторные иконки манифеста** (загружаются через слоты).
2. **Рабочий бэкенд админки** (БД + авторизация + хранилище фото) вместо
   `localStorage` — например self-host CMS или Supabase на РФ-хостинге.
3. **Локализация зависимостей** (React/Babel) вместо CDN unpkg для
   стабильной работы из РФ.

## Редактирование дизайна

`index.html` — это файл Claude Design. Чтобы продолжить править дизайн в
claude.ai/design, переименуйте его в `Сайт ВЯЗ.dc.html` и импортируйте.
Доработки кода и бэкенда ведём здесь, в репозитории.
