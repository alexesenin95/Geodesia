# Сайт МБУ «ВЯЗ»

Сайт Центра стратегического планирования Волгограда «ВЯЗ» — лендинг,
внутренние страницы и **панель управления контентом с серверным бэкендом**.

Дизайн создан в Claude Design по референсу [lda-design.co.uk](https://www.lda-design.co.uk).

## Архитектура

- **Фронтенд** — `public/index.html` (исходный файл Claude Design на рантайме
  `support.js`). React/ReactDOM подключены **локально** из `public/vendor/`
  (без CDN — работает в РФ без VPN).
- **Бэкенд** — Node.js + Express (`server/`): отдаёт сайт, хранит контент,
  авторизует админа (JWT), принимает загрузку изображений.
- **Хранилище контента** — JSON-файл `data/content.json` (создаётся из
  `server/seed.json` при первом запуске).
- **Загруженные фото** — папка `uploads/`, отдаётся по `/uploads/...`.

```
public/        # статический фронтенд
  index.html   # весь сайт + логика CMS
  support.js   # рантайм Claude Design
  vendor/      # React, ReactDOM (локально)
  assets/      # логотипы
server/
  index.js     # Express-сервер (API + статика)
  seed.json    # стартовый контент (реальные данные «ВЯЗ»)
data/          # content.json (в .gitignore)
uploads/       # загруженные изображения (в .gitignore)
```

## Запуск

```bash
npm install
cp .env.example .env      # отредактируйте секреты и пароль
npm start                 # → http://localhost:3000
```

## Переменные окружения (`.env`)

| Переменная | Назначение | По умолчанию |
|------------|-----------|--------------|
| `PORT` | Порт сервера | `3000` |
| `JWT_SECRET` | Секрет для токенов — **смените в проде** | `change-me-...` |
| `ADMIN_USER` | Логин админа | `admin` |
| `ADMIN_PASSWORD` | Пароль админа (хэшируется при старте) | `vyaz` |
| `ADMIN_PASSWORD_HASH` | Готовый bcrypt-хэш (вместо пароля) | — |

## Панель управления

Открывается из футера → «Панель управления» (или `/` → прокрутка вниз).

- **Доступ по умолчанию:** `admin` / `vyaz` (смените через `.env`).
- Разделы: проекты, новости, услуги, КРТ, команда, манифест, настройки.
- **Загрузка изображений** прямо в админке:
  - проекты и площадки КРТ — галерея (несколько фото, слайдер на странице);
  - новости и команда — одно фото;
  - манифест — векторная иконка (SVG/PNG) к каждому из 6 принципов;
  - настройки — фото бюро на странице «О нас».
- Данные сохраняются **на сервере** (`data/content.json`) — видны всем
  посетителям, а не только в одном браузере.
- Где фото не загружено — показывается фирменная градиентная заглушка.

## API

| Метод | Путь | Доступ | Назначение |
|-------|------|--------|-----------|
| `GET` | `/api/content` | публичный | весь контент сайта |
| `POST` | `/api/login` | публичный | вход, возвращает JWT |
| `PUT` | `/api/content` | по токену | сохранить контент |
| `POST` | `/api/upload` | по токену | загрузить изображение |

## Деплой

Нужен Node.js (≥18) на сервере (подойдёт любой РФ-VPS — Timeweb, Selectel и т.п.):

```bash
npm ci
NODE_ENV=production npm start     # лучше под pm2/systemd, за Nginx
```

`data/` и `uploads/` должны быть **постоянными** (бэкапить) — там весь контент
и фото. Для статики/`/uploads` можно поставить Nginx-кэш.

## Страницы сайта

Главная (карусель проектов + новости), Проекты (с фильтрами), О нас
(о бюро, **манифест — 6 принципов с иконками**, команда), Услуги,
КРТ (площадки по районам), Контакты, Вакансии, страницы проекта и площадки.

## Редактирование дизайна

`public/index.html` — это файл Claude Design. Чтобы продолжить правки дизайна
в claude.ai/design, переименуйте его в `Сайт ВЯЗ.dc.html` и импортируйте
(учтите: серверная логика API при этом не нужна Claude Design — она работает
только на этом сервере). Доработки кода и бэкенда ведём здесь, в репозитории.
