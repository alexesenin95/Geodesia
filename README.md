# Сайт МБУ «ВЯЗ»

Сайт архитектурного бюро (Волгоград): работы/проекты, услуги, новости, инвестиционные
площадки (КРТ), нормативные документы, команда, контакты и встроенная **админ-панель**.

Сайт — статический (`index.html` + рантайм на React из CDN), а для загрузки файлов
(фото и PDF) есть небольшой **бэкенд** на Node.js.

## Структура

```
index.html                  весь сайт (вёрстка + логика + админка)
support.js                  рантайм рендеринга
image-slot.js               компонент картинок (читает .image-slots.state.json)
.image-slots.state.json     карта изображений (base64 + ссылки на загруженные файлы)
assets/                     логотипы
uploads/                    загруженные через админку файлы (фото .webp и PDF)
server/                     бэкенд: загрузка фото и PDF, хранение контента
```

## Запуск с бэкендом (рекомендуется — работает загрузка фото и PDF)

Нужен установленный **Node.js 18+**.

```bash
cd server
npm install          # один раз: ставит express, sharp, mupdf (всё без компиляции)
npm start            # запускает сервер на http://localhost:8000
```

Открыть в браузере: **http://localhost:8000**

Сменить порт или пароль:

```bash
PORT=3000 VYAZ_ADMIN_PASSWORD=мой-пароль npm start
```

### Как загружать контент

1. Внизу страницы — ссылка **«Панель управления»**.
2. Вход: логин `admin`, пароль — значение `VYAZ_ADMIN_PASSWORD` (по умолчанию `vyaz`).
3. В разделе **«Работы»** или **«Площадки»** открой/создай объект → в карточке:
   - **«📷 Загрузить фото (пакетом)»** — выбери сразу несколько фото. Они
     автоматически ужимаются в **WebP** и добавляются в галерею.
   - **«📄 PDF → страницы-фото»** — загрузи PDF: каждая страница станет картинкой
     в галерее, а сам PDF привяжется к кнопке «Скачать».
4. В разделе **«Документы»** / **«Нормативные акты»** — кнопка **«📄 Загрузить PDF»**:
   файл сохранится и появится с кнопкой скачивания.

Загруженные файлы сохраняются на сервере (папка `uploads/`), а структура контента —
в `server/data/content.json`, поэтому изменения видят все посетители.

## Запуск без бэкенда (только просмотр)

```bash
python -m http.server 8000
```

Сайт откроется и будет работать, но загрузка фото/PDF через админку будет недоступна
(нет сервера для приёма файлов) — можно только просматривать и править тексты локально.

## Деплой

Для рабочего сайта нужен хостинг с поддержкой Node.js. Запускается `server/server.js`
(он же отдаёт статику сайта и папку `uploads/`). Пароль админки задаётся переменной
окружения `VYAZ_ADMIN_PASSWORD`.
